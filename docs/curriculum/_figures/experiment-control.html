Adaptive search

Choose again after observing a result.

  1. A0.81
  2. B′0.84
  3. C′0.82

A’s score informs B′. B′’s score informs a replication, C′. B′ wins after trial 3.

Fixed horizon ≠ open loop. Both runs stop after three experiments. The adaptive run can still change which configuration it tries next.
