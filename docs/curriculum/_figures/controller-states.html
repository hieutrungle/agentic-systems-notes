Reading the diagram

  • The policy chooses this edge.
  • The gate, scheduler, evaluator, clock, or a controller rule fires this edge.
  • A hard stop leaves the Search group from any mode inside it.
  • An edge leaving a group applies to every mode in the group.

Every return path enters Ready. The stop rule runs there before each policy turn.

Invalid output and failed jobs also return to Ready. The transition table lists them.
